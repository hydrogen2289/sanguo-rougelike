## 4. 伪3D渲染方案

已拍板:真 3D 场景 + 斜俯视透视相机(约 50°~60° 俯角)+ Sprite3D 立牌(Y 轴 billboard)+ 方向光软阴影 + 环境雾 + 3D 平面地面;不是纯 2D 投影。开工基准参数(允许 ±10% 内微调):

| 项 | 参数 |
|---|---|
| Camera3D | perspective,fov 45°,**俯角 55°**(区间 50~60 取中);跟随主公,lerp 5.0/s |
| 相机位姿 | CameraRig 挂主公,offset = (0, 13.1, 9.2)(= 高 13.1 / tan55° ≈ 9.2),look_at 主公 + (0, 0.6, 0);主公呈现在屏幕下 1/3 |
| Sprite3D 立牌 | billboard = `BILLBOARD_FIXED_Y`;pixel_size = 0.005(320px → 世界高 1.6m);position.y = 0.8(脚底贴地);shaded = true;**alpha_cut = ALPHA_CUT_OPAQUE_PREPASS**(保证阴影与深度排序正确);texture_filter = LINEAR_WITH_MIPMAPS |
| DirectionalLight3D | rotation (-52°, -30°, 0°);energy 1.15;color #FFF6E0;shadow_enabled;directional_shadow_mode = PSSM_2_SPLITS;max_distance 45;soft_shadow_filter_quality = 高 |
| WorldEnvironment | background 纯色 #F2EAD3;ambient_light 颜色 #DCE4D8、energy 0.6;fog_enabled,fog_light_color #E8E0C8,fog_density 0.012,fog_sky_affect 0;tonemap = FILMIC;glow 关闭(保淡彩) |
| 地面 | PlaneMesh 60×60;StandardMaterial3D:albedo = ground_paper.png(512,程序化),uv1_scale (12, 12, 1),roughness 1.0;可用区 40×40,四边 Wall + 卷轴渐隐 vignette |
| 单位朝向 | 立牌不旋转(billboard);攻击方向用贴图水平翻转(H flip)与 VFX 角度表达 |

- **落地感来源**:立牌 OPAQUE_PREPASS alpha cut + shaded,方向光把人物影子投在地面上;同屏 ≤ 60 单位,阴影 max_distance 覆盖全屏。
- **性能目标**:1080p 稳 60 FPS(GTX 1060 级);同屏敌兵 > 80 时预留「降软阴影质量」开关。

## 5. 程序化贴图生成

目标:全部视觉素材由 GDScript 绘制生成 PNG,不下载任何素材(已拍板)。采用**离线烘焙进仓库 + 校验**,不做运行时生成(避免首帧卡顿与不确定性)。

**生成流程(5 步)**:
1. **调色板**:`data/palette.json` 定义全部色 token(见 01 文档第 11 节);生成脚本只引用 token,不写死色值。
2. **脚本**:`tools/gen_textures.gd`(SceneTree 脚本),内部为一组 `draw_xxx(img: Image)` 函数;纸纹/草渍等随机纹理用**固定 seed** 的 RandomNumberGenerator,保证可复现。
3. **绘制**:`Image.create` + 辅助函数(画圆/画线/描边);角色按「头圆 → 身椭圆 → 识别物 → 2px 深褐描边」顺序绘制。
4. **落盘**:`save_png` 写入 `assets/textures/**`,同时生成 `manifest.json`(文件名/尺寸/seed)。
5. **校验**:`tests/test_textures.gd` 比对 manifest 与实际文件(存在/尺寸/非全透明),纳入 run_all。

**运行命令**:`godot.cmd --headless --path "E:\Vibe Coding\zcode\三国肉鸽" --script res://tools/gen_textures.gd`
音频同管线:`tools/gen_audio.gd` → `assets/audio/*.wav`(16bit PCM,44100Hz)。

## 6. 数据层设计

- 全部数值表用 **JSON** 存 `data\`;启动时 `DataDB`(autoload)一次性加载并做 schema 校验:缺字段/数值越出 01 文档锚点区间即 fail fast,打印「表名 + 行号」;调平衡只改 JSON,不动代码。
- 表文件:palette / heroes / enemies / waves / relics / upgrades / events / shop(共 8 个,见目录树)。
- **Schema 示例**(heroes.json 节选):
```json
{
  "id": "guanyu", "name": "关羽", "is_lord": false,
  "hp": 85, "atk": 14, "atk_speed": 0.9, "range": 1.8, "move_speed": 4.0,
  "skill": {"id": "qinglong_sweep", "name": "青龙偃月·扫", "cd": 8.0,
            "type": "cone", "angle_deg": 120, "radius": 3.0,
            "dmg_mult": 2.5, "knockback": 1.0},
  "trait": {"id": "execution", "threshold_ratio": 0.15, "boss_immune": true},
  "recruit_min_wave": 0
}
```
- **RunState(autoload,单局状态)**:`run_seed`、`rng`(全部随机走它:三选一/不受令/掉落/货架刷新,保证可复现)、`gold`、`wave_idx`、`team: [unit_state]`、`relics: [id]`、强化叠加表、计时器。
- **数值合成模型**:修饰符分三类——flat(+10 HP)、add%(攻击 +8%)、特判(斩杀/狂化/灼烧);最终属性 = base × (1 + Σadd%) + Σflat;技能 CD 最终 = base × (1 − ΣCD缩减),总缩减封顶 40%;同名遗物唯一由 relics 表去重。
- **结算快照**:`RunState.dump()` 输出本局统计(到达波次/总击杀/剩余军资/用时/队伍构成),供结算页与 CSV 日志。

## 7. 核心系统实现要点

按系统列实现约定(GDScript,随机一律走 `RunState.rng`):

1. **移动与跟随**:主公读 Input 沿 XZ 平面,`velocity = dir × 4.2 × mods`;武将目标点 = 主公位置 + 队形偏移(formation.gd:槽位 i 在主公后方 150° 扇形均布,r=1.5m);与主公距离 > 5m 时移速 ×1.5 归队;软分离:对 0.9m 内邻居叠加排斥位移。
2. **索敌与普攻**:0.2s 定时器扫描 `enemies` group 取最近;近战 = 计时到且目标在 MeleeRange 内 → `target.take_damage()`;远程 = 实例化 projectile(直线飞行,Area 判定命中);目标死亡自动重索敌。
3. **技能系统**:skill_component.gd 持 CD 计时;`activate()` 时吕布先掷「不受令」(`rng < 0.30` → 入延迟队列 3s,生效时每段伤害 ×1.5,HUD 图标红闪);技能实现为 7 种数据驱动原型:cone(关羽)、nova+击退+眩晕(张飞)、dash(赵云)、weather(诸葛亮)、heal_all(华佗)、shield(刘备)、triple_nova(吕布)。
4. **个性机制**:拖刀计 = 普攻命中回调里判 `target.hp ≤ max × 0.15` 且非 Boss → 直接 hp=0 +「斩」浮字;狂化 = HP 比例跨 0.35 挂 buff、回升跨 0.50 摘除(攻速 ×1.4、攻距 ×1.3、每 5s 吼退 2m);光环 = AuraZone 每秒 tick 回复;护盾 = 单位 shield 池,伤害先扣盾、到期清零;灼烧 = 目标身上 dot{2 伤害/0.5s, 3s} ×(1 + 火伤加成)。
5. **波次状态机(wave_director.gd)**:`PRELUDE(横幅 3s) → SPAWNING(按 waves.json 节奏环形刷怪,半径 = 相机视野外 2m) → BATTLE(计时;全灭或计时到 → 剩余普通敌退场) → INTERMISSION(按排程弹三选一/事件/商店) → 下一波`;第 8 波特殊:击杀华雄才结束,二阶段召唤挂 PhaseController。
6. **经济与掉落**:敌死 → 生成 pickup_gold(单枚 1~3,每波总额对齐 waves.json 的 15~30);磁吸半径 2.5m,吸入 +gold + 音效。
7. **死亡处理**:敌兵 → 0.5s 淡出;武将 → modulate 灰化倒地 2s 后移除、头像打叉、从 team 摘除(不可复活);主公 → `EventBus.lord_died` → 失败结算。
8. **天气**:weather_manager.gd `set_eastwind(10s)` → 全局 fire_mult = 1.3、普攻命中回调附加灼烧、全屏色罩 tween 12% 春青;结束回 normal。
9. **暂停与结算**:`get_tree().paused` 下波间界面照常响应(用 process_mode 区分);主公死/华雄死 → `RunState.dump()` → result 场景;重开 = SceneRouter 重载 battle + `RunState.reset(new_seed)`。
10. **性能**:敌兵 AI 共用 0.2s 决策节拍;浮字/特效走对象池(object_pool.gd);group 扫描代替物理查询。

## 9. 自测与验收钩子
