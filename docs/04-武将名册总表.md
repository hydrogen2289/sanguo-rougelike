# 《桃源乱武》武将名册总表(2026-11-04)

文档用途:后续武将扩池的总规划,规定分批名单、定位、技能原型(复用/新增)、形象锚点与配套规则;与《01-设计文档.md》《03-武将扩池-第二批.md》配对使用。
版本:v0.1(全部数值均为占位,逐批实现时才定稿;本文档只锁「名单+定位+原型」,不锁数值)

---

## 1. 规划原则

1. **原型复用优先**:每批新增技能原型 ≤3 个(每做一个原型≈做一个新系统,成本远高于一个武将);能用 dash/charge/snipe/frenzy/灼烧/治疗/护盾/光环/延迟等既有原型拼出定位的,不造新原型。
2. **定位互补优先**:先补玩法空位(肉盾、控制、AOE、火系 build、召唤),再补人气角色。
3. **满员换人配套**:名册超过 10 将后「满员即锁死」问题会持续放大,换人规则必须与第三批同批落地(见 §5)。
4. **阵营平衡**:每批尽量跨势力,避免一口气堆满蜀汉。
5. **形象纪律**:全部沿用 unit_rig_3d.gd 程序化拼装 + palette 8 色 token,零外部素材;形象锚点以演义/脸谱公认特征为准。

## 5. 满员换人规则(提案,随第三批落地;直接回应设计评审 H2/H3「满员即锁死、无替补池」)

1. **替换卡**:满员时三选一仍可出武将卡,卡面变为「替换:指定一名在场武将离队」;被换者**保留**(入候选池可再抽回,不视为阵亡)。给「要不要为马超卖掉张飞」的决策。
2. **阵亡补位**:武将阵亡后,武将卡恢复出现在三选一池(填补空位),呼应「折将不可复活」但给翻盘窗口——折将仍是本局永久损失,只是队伍规模可回补。
3. **替补席(可选,待拍板)**:商店出售「募兵令」直接从候选池指定招募 1 名(60~80 军资占位),与吕布事件付费天花板逻辑对齐。
4. 数值不动的底线:换人不产生即时数值跳变(替换下来的人才走 buffs 全回收,复用魏延反骨「不进全局 mods」的口径经验)。
