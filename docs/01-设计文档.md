## 1. 概述与三层结构总览(新定位)

- **题材与定位**:三国题材「局外养成 × 组队推图 × 肉鸽爬塔」三层数值循环游戏;PC 单机(Windows)。
- **对标**:局外养成层对标《百炼英雄》(主城 + 武将招募养成 + 经济),组队闯关层对标三国志式推图(章节/关卡/评星),肉鸽试炼塔层对标《土豆兄弟》式幸存者爬塔(随机波次 + 三选一 build)。
- **引擎与表现**:Godot 4.7.2 stable + GDScript;真 3D 场景 + 程序化拼装 3D 低模小人 + 斜俯视相机(参数见 02 §9);Q 版国风淡彩;全部素材程序化生成(约束 4)。

| 层 | 内容 | 对标 | 玩家动作 | 产出 |
|---|---|---|---|---|
| 层一 · 局外养成(主城) | 武将招募/升级/升星、货币管理、上阵编队 | 百炼英雄 | 消耗资源变强 | (跨局持久) |
| 层二 · 组队闯关 | 章节/关卡推图,固定波次脚本,评星 | 三国志式推图 | 上阵选将 → 打固定关卡 → 拿评星 | 军资/碎片/新武将/解锁进度 |
| 层三 · 肉鸽试炼塔 | 随机波次爬塔 + 三选一 + 局内 build | 土豆兄弟式幸存者 | 连续爬层,局内滚雪球 | 军资/碎片(按层数结算) |

**总循环**(一分钟/一局/一存档三级循环):

- **一局循环(战斗内,两模式共用)**:战斗(走位/自动普攻/技能)→ 波间(塔内为三选一/事件/商店)→ 波次推进 → 结算。
- **一次出征循环**:主城编队 → 进关卡/塔 → 多波战斗 → 胜利(或撤退/主公阵亡)→ **结算奖励写入存档**(§8)。
- **一存档循环**:用军资升级武将、用碎片合成/升星 → 队伍变强 → 推进更远的章节/更高的塔层 → 更丰厚的奖励 → 继续养成。**经济闭环成立**(约束 2)。

**肉鸽张力来源(沿用已拍板)**:主公(刘备)阵亡 = 本次出征失败;武将阵亡 = 本次出征内退场,不可复活。

## 2. 层一:局外养成 · 主城

主城是跨局存档的操控台与唯一出发地(场景与界面流见 02 §7)。

### 2.1 主城功能

| 功能点 | 说明 | 对应界面 |
|---|---|---|
| 校场 | 上阵编队(闯关模式席位管理)、查看队伍战力 | 编队界面 |
| 酒馆 | 武将招募:军资直购 + 碎片合成(§7.3,待拍板) | 招募界面 |
| 武将府 | 武将升级(军资)/升星(碎片)、查看属性与技能 | 养成界面 |
| 战役面板 | 章节选关、评星总览、评星宝箱 | 选关界面 |
| 试炼塔入口 | 进入试炼塔(层三),显示历史最高层 | 塔入口 |
| 钱库 | 军资/碎片余额与来源流水(只读) | HUD 常驻 |

- 主城不做战斗玩法、不做基地建设(版本边界:建筑仅作为**功能入口的命名**,不单独做建筑升级系统;若要做随建筑解锁功能的「主城建设度」,属待拍板扩展,见 §13)。

### 2.2 武将招募(提案,待拍板)

武将获取三途径:

1. **初始赠送**:刘备/关羽/张飞(桃园三人组)开局即有,不可出售/降星。
2. **战役首通解锁(提案)**:部分名将绑定章节关卡首通(如华佗绑定 1-5、诸葛亮绑定 1-7、吕布绑定 1-8 通关;具体绑定表占位待拍板)——保证推图动力与「免费获取主力」下限。
   - **实装现状(2026-11-06 实测,与上句不同,勿混淆)**:`data/campaign.json` 的 `first_clear` **只绑定了碎片、没有绑武将本体**——`1-2→{huatuo:5}`、`1-5→{zhuge:5}`、`1-8→{lvbu:5}`,其余 5 关只有军资。`campaign_save.settle_stage()` 经 `SaveState.add_fragments()` 只入碎片,**全仓无「首通直接 `owned` 一名武将」的写入路径**(`hire`/`unlock_hero` 类 API 不存在)。即:**上句写的「首通解锁名将」当前等于「首通给 5 枚该将碎片」,不是直接获得武将**;5 枚也远低于合成门槛(华佗 rare 40 / 诸葛亮、吕布 epic 80)。真实绑定关卡也与上句举例不同(华佗在 **1-2** 而非 1-5,诸葛亮在 **1-5** 而非 1-7)。
3. **酒馆招募(§7.3)**:军资直购或碎片合成补齐其余武将。

### 2.3 武将养成(升级/升星)

- **升级**:消耗军资提升等级,等级提高 HP/攻击(曲线框架与占位公式见 02 §5)。
- **升星**:消耗同名武将碎片提升星级(1~5 星),星级按百分比放大全属性(02 §5)。
- 养成乘区作用于**武将出场基础值**:局内修饰符体系(遗物/强化/事件)不变,两者叠乘关系见 02 §5.4。
- 数值全部为**框架与占位**,不要求调平衡(02 §5 给曲线形式,验收实测后调)。

### 2.4 校场与上阵(席位已拍板:采用实现值)

- **上阵席位(已拍板(2026-11-06):采用实现值,见 data/economy.json:26 `item_price.slot_cap`、scripts/meta/hero_save.gd:207-220、scripts/autoload/save_state.gd:19-20)**:原提案「闯关模式初始 3 席(主公 + 2 武将)→ 解锁至 5 席(主公 + 4 武将);试炼塔保持 7」→ 实现值「**席位统一 3→7,不按模式区分**:`buy_slot_cap` 上限恒 `SaveState.MAX_SLOT_CAP=7 = RunState.MAX_TEAM`,`economy.json:26` 价格表 4 档 `[500,1200,2400,4000]` 正好覆盖 3→7,战役/塔两入口共用同一 `squad_edit` 面板、不区分 mode(`scripts/ui/main_city.gd:76-89`、`scripts/ui/squad_edit.gd:167`)」→ 已拍板。`slots[0] 恒 liubei`、主公固定 1 席由玩家操控不变。
- 未上阵武将不在战斗中出现(候选席),无「替补中途换人」(第三批换人规则落地后再评估是否用于闯关)。

## 3. 层二:组队闯关(主线推图)

### 3.1 章节与关卡

- 结构:**章节 → 关卡 → 波次脚本**。每章 6~10 关(占位),每关 1~3 波(短关卡,单关 2~5 分钟,区别于塔的长战斗)。
- 波次脚本为**固定内容**(非随机):沿用现有 waves.json 的剧本契约(theme/objective/spawn_plan 分批投放/arc 扇区/reinforcement 增援,数据结构见 02 §4.3)。关卡写死敌人构成、来向、批次,同一关卡每次进入完全一致。
- 章节叙事:每章开篇章卷轴 + 关卡主题名(沿用「第 X 波 · 主题」横幅格式)。

### 3.2 上阵与出战

- 进关前经校场编队,按 §2.4 席位上阵;主公刘备必须上阵且为玩家操控(主公阵亡 = 本关失败,沿用已拍板)。
- 武将阵亡 = 本关内退场不可复活(沿用);本关失败(主公阵亡或全队阵亡)后可**直接重打**,不损失存档资源(失败不扣军资;是否加每日/次数限制:不做,待拍板可否决)。

### 3.3 评星(提案,待拍板)

| 星 | 条件(占位提案) |
|---|---|
| ★1 | 通关 |
| ★2 | 通关且无武将阵亡 |
| ★3 | 通关且主公结算 HP ≥ 50% |

- 每关独立评星,取历史最高;章节内总星数开启**评星宝箱**(军资/碎片,数量占位待拍板)。
- **实装现状(2026-11-06 实测)**:上表三条规则**已按原样实装**,不需要推翻提案——`campaign_save.gd:115 calc_stars()` 完全对应:`victory=false → 0`、`no_casualty → 2`、`lord_hp_ratio >= LORD_HP_STAR3(0.5) → 3`。宝箱为 3/6/9 星三档,军资 **200 / 400 / 600**(第一章满 ★3 共 24 星,三档全开)。`test_campaign.gd:197 _test_progression_and_boxes()` 覆盖评星/宝箱/重复领取拒绝。

### 3.4 推图解锁

- 线性解锁:通关 N 关解锁 N+1 关;通关整章解锁下一章。
- 功能解锁(提案,待拍板):酒馆/试炼塔/升星等主城功能随章节进度开放(如酒馆 1-3 后、试炼塔 1-2 后、升星 1-4 后;具体节点待拍板)。已实装玩家(老档)全部直接开放。

### 3.5 首章内容规划(占位)

- 第一章「桃园篇」:8 关(占位)。1-1~1-7 为黄巾军小波次关卡(复用现有敌兵池:黄巾卒/弓手/力士),1-8 为**华雄 Boss 关**(复用现有 boss_huaxiong 资产,三技能 + 二阶段);具体波次脚本由后续关卡设计任务卡排产(类似《03-关卡设计.md》模式),本文档不锁数值。
- 第二章起(Boss 线按 04 总表:颜良&文丑 → 袁绍 → 董卓 → 曹操)另行派卡。

## 5. 战斗规则(闯关与试炼塔共用,约束 1)

以下规则两种模式完全一致,战斗核心一套代码(实现见 02 §8):

**操控(已拍板,混合操控)**:
- 主公:WASD 走位躲弹,唯一玩家直控单位;主公普攻全自动(双股剑近战,数值弱势,输出靠武将)。
- 武将:跟随单位,自动索敌(8m 内最近敌人)自动普攻,无需玩家指挥。
- 技能:每名武将 1 个冷却制主动技能;按数字键 1~6(对应队伍槽位)或点击 HUD 技能按钮;技能以宿主当前位置/索敌目标自动判定范围,无需瞄准。

**战斗规则(沿用已实装)**:
- 伤害公式:最终伤害 = max(1, round(攻击力 × 技能倍率));灼烧等持续伤害独立结算。
- 技能开局即减半冷却,可较早释放首技。
- 控制效果:击退(0.3s 衰减)、眩晕(禁 AI 与普攻);Boss 华雄免疫击退/眩晕/斩杀;精英力士击退抗性 50%。
- 掉落:敌兵死亡掉军资(自动磁吸半径 2.5m 飞向主公);波内不掉治疗品。
- 波次结束:全灭或计时结束即结束;计时到在场的普通敌人自动退场(不给军资);Boss 层(塔第 8 层、闯关 Boss 关)必须击杀 Boss 才结束。
- 队伍:上限见 §2.4(已拍板(2026-11-06):席位统一 3→7、不按模式区分,取代原「塔 7 / 闯关提案 3~5」);武将阵亡当场灰化退场本局不可复活;主公阵亡立即失败。

## 6. 武将名册与养成维度
