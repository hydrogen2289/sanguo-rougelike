# 《桃源乱武》垂直切片 · 关卡设计（8 波剧本）

- 版本：v0.2（2026-11-04，基于实机试玩反馈重设计；替代 01 文档 §6 的平衡占位波次表）
- 数据落点：`data/waves.json`（唯一数值来源）；引擎支持：`scripts/battle/wave_director.gd`、`scripts/battle/spawner.gd`、`scripts/autoload/data_db.gd`
- 验收钩子：`tests/test_levels.gd`（经 `tests/run_all.gd` 汇总）

---

## 1. 设计目标与依据

11-04 实机试玩 4 局，3 局主公在第 2 波阵亡（75s / 66s / 42s），第 4 局仅撑到第 2 波计时结束。原波次表的问题不是单点数值，而是**曲线结构**：

1. **W2 断崖**：近战 10→12、新增 3 名远程弓手、基准攻击 5→6，三项同时抬升；且均匀刷新使弓手从第 0 秒就混在近战里点射主公，玩家没有反应窗口。
2. **波次同质**：8 波都是「全向环形均匀刷怪 + 堆数量」，唯一变化是数字变大，走位与 build 决策没有新的输入。
3. **缺少关卡语义**：玩家不知道这一波要「做什么」，只有「第 X 波」。

本版据此重设计，四条原则：

- **前 3 波是教学曲线**：一次只引入一个新变量（W2 弓手、W3 力士），且新变量延后投放。
- **分批 + 来向替代单纯堆量**：压力来自节奏与方位，不来自敌人数；总敌兵数由 176 降至 147（−16%）。
- **张弛有度**：波间事件/商店（W2/W4/W6）前不放最高压，W7 为常规波峰值，W8 为机制完全不同的 Boss 关。
- **口径不破**：8 波、W2/4/6 事件、W4/6 商店、第 8 波必杀华雄、所有数值锚点（时长 25~45s、基础 HP 15~30、攻击 3~12、掉落 15~30）保持不变。

## 2. 数据契约（新增字段）

| 字段 | 类型 | 含义 |
|---|---|---|
| `theme` | string | 关卡名，显示在波次横幅「第 X 波 · 主题」 |
| `objective` | {type,label} | 关卡目标；`type` 为剧本分类（clear / elite / pincer / survive / boss），`label` 在刷怪开始时以提示横幅呈现 |
| `spawn_plan.arc` | [起,止] 度 | 本波默认刷怪扇区；批次可用自己的 `arc` 覆盖 |
| `spawn_plan.batches` | [{t,spawn,arc?}] | 分批投放：`t` 为进入 SPAWNING 后的秒数，`spawn` 为该批敌人构成 |
| `reinforcement.arc` | [起,止] 度 | 第 8 波增援来向 |

**角度约定**：0° = +X（东），90° = +Z（南），±180° = −X（西），−90° = −Z（北）。扇区以主公为圆心、半径 12~15m 的环上取样，越界仍钳制在 40×40 战场内。

**硬约束**（由 `DataDB._validate_waves()` 与 `test_levels.gd` 双重校验）：

- 所有批次 `t` 必须落在 `[0, duration × 0.5]`，保持 `SPAWN_WINDOW = 0.5` 的总体投放窗口，平衡模拟（`test_balance_sim`，按均匀投放近似）仍然成立。
- 批次时间单调不减；各批 `spawn` 按敌人 id 汇总必须**逐项等于** `composition`，不许出现「配置了但不刷」或「刷了但没配」。
- `arc` 必须长度 2、`起 < 止`、均在 −180~180 内，且 `composition` 引用的敌人 id 必须存在。
- 无 `spawn_plan` 的波次回退到旧版均匀刷新逻辑（向后兼容）。

## 4. 难度曲线（与 v0.1 对比）

| 波 | 旧：敌数 / 攻击 | 新：敌数 / 攻击 | 变化意图 |
|---|---|---|---|
| 1 | 10 / 5 | 8 / 5 | 开局减负，留时间认识自动索敌 |
| 2 | 15 / 6 | 11 / 5 | **断崖修复**：攻击不升、弓手 3→2 且延后 13s |
| 3 | 20 / 6 | 15 / 6 | 力士 2→1 且压轴，作为「精英登场」教学 |
| 4 | 25 / 7 | 21 / 6 | 商店前的压力缓一档，让经济决策有余裕 |
| 5 | 31 / 8 | 26 / 7 | 用南北夹击换掉 5 个敌兵 |
| 6 | 35 / 8 | 30 / 8 | 事件+商店前保持递进，不叠加数值 |
| 7 | 40 / 9 | 36 / 9 | 常规波峰值，三面合围制造走位压力 |
| 8 | Boss | Boss | 不变 |

曲线特征：前 4 波每次只抬一个维度（数量或攻击不同时抬），W5 起恢复同步增长；基准攻击 5→5→6→6→7→8→9→10 单调不降但梯度减半，主公在 W2 不再被远程集火秒杀。

## 5. 关卡与 build 决策的耦合

- W2 事件「鞭打督邮」在弓手首次登场之后，玩家刚体会过远程压力 → A 选项（张飞攻击 +15% / 全队 −10HP）与 B 选项（+15 军资）的取舍有了情境。
- W4 商店①前是双路分批波，玩家会意识到「清场速度」的价值 → 连弩图 / 磨刀一类攻速攻击装的购买动机更明确。
- W6 商店②紧接「虎牢关·飞将来投」（吕布 60 军资），第三批峰值刚过 → 花钱招天花板 vs 留钱买遗物的经济冲突成立。
- W7 三面合围后直接进 Boss，是队伍成型的最后检验；此时空格主公技（护盾 20 + 回复 12，CD 10s）与治疗型武将的价值最高。

调参顺序建议：先实机完整打一局记录各波清波用时与主公 HP 曲线；若 W2 仍偏难，优先调 `batches` 里弓手的 `t`（往后再推 2s），而不是再降 `base_atk`——后者会连带削弱后面所有关卡的手感。若单局总时长偏离 8~10 分钟，调 `duration` 与波间弹窗信息量，不要动分批批次数量。
