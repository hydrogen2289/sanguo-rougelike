# 合规清单

日期：2026-11-06
依据：`docs/01-设计文档.md:16`（Windows PC 单机）、`docs/release/pipeline-status-2026-11-06.md`、`docs/release/assets-license.md`；代码扫描（`grep http|HTTPRequest|telemetry|analytics`）

## 先说一个有利事实

**游戏完全离线。** 全仓 `grep -rn "http|HTTPRequest|network|telemetry|analytics"` 在 `scripts/` 下**零命中**——没有任何联网调用、没有数据上报、没有账号系统。

所有落盘只有两处，都在本机：

- `scripts/autoload/save_state.gd:4` → `user://save_v1.json`（存档）
- `scripts/util/csv_logger.gd:6` → `user://wave_log.csv`（调试用波次日志）

**这大幅降低了合规负担。** 没有服务器就没有数据出境、没有《个人信息保护法》的跨境传输问题、没有 GDPR 的数据处理者身份。

## 按发行地分列

### 一、中国大陆发行

| 事项 | 现状 | 是否阻断 | 说明 |
|---|---|---|---|
| **游戏版号（ISBN）** | ❌ 无 | 🔴 **阻断（若走国内正式发行）** | 在中国大陆以任何形式向公众提供网络游戏，需版号。单机游戏若不涉及联网、以实体或纯下载形式销售，实际执法口径**需核实**——但上国内应用商店/渠道（WeGame、TapTap 国内版等）一律要求版号，无例外。申请周期通常以**年**计，且个人主体申请渠道受限。 |
| **软件著作权登记（软著）** | ❌ 无 | 🔴 **阻断（若走国内渠道）** | 国内渠道上架普遍要求软著证书。周期以**月**计。**需核实**各家渠道具体要求。 |
| **隐私政策** | ❌ 无 | 🟡 不阻断（因为不收集数据） | 因完全离线、不收集任何个人信息，理论上不需要完整隐私政策。但若上任何国内平台，平台表单仍会要求勾选「是否收集个人信息」并提供说明。**建议准备一份「本游戏不收集任何个人信息」的一句话声明**，成本极低。 |
| **税号 / 纳税人识别号** | ❌ 无 | 🔴 **阻断（若要收款）** | 国内渠道结算必须提供对公账户与税务登记信息。个人开发者若要拿钱，需个体工商户或公司主体。**这是钱的问题，只能人决定**。 |
| **未成年人保护 / 防沉迷** | ❌ 无 | 🟡 待定 | 单机无联网、无充值，是否需要接入实名认证系统**需核实**。若纯免费单机分发，一般不涉及。一旦有内购，就必须接入。 |
| **游戏内容审查（价值观/历史观）** | ⚠️ 未评估 | 🟡 | 三国题材本身有历史观审查风险（如对历史人物的处理）。**需核实**具体尺度。当前游戏无血腥暴力烈度描述，风险较低。 |

**小结：走国内正式渠道，当前是 0 准备。版号 + 软著 + 主体资质三件套缺一不可，且都不是能靠工程解决的。短期不建议作为首发渠道。**

### 二、Steam（国际 + 国区）

| 事项 | 现状 | 是否阻断 | 说明 |
|---|---|---|---|
| **Steamworks 账号** | ❌ 无 | 🔴 阻断 | 需注册，需提供身份与税务信息（W-8BEN 等）。**必须人本人操作**。 |
| **Steam Direct 提交费** | ❌ 未付 | 🔴 阻断 | 每款产品一笔，金额**需核实**（不凭记忆写具体数字）。收回条件也有门槛，**需核实**。 |
| **税务表格** | ❌ 无 | 🔴 阻断（若要分成） | 美国预扣税表 W-8BEN，需填中国纳税人信息。填错会多扣税。**必须人本人操作**。 |
| **商店页内容分级** | ❌ 无 | 🟡 不阻断但必须做 | Steam 自带内容问卷，提交时必填。本作无暴力血腥烈度、无成人内容，预计评级很低。 |
| **版号** | ❌ 无 | 🟡 **Steam 国区特殊** | Steam 国际版不需要版号。但 Steam 中国版（蒸汽平台）需要。**需核实**当前 Steam 在国区的实际运营形态。若只上国际版，不涉及版号。 |
| **GDPR（欧盟玩家）** | ❌ 无 | 🟢 不阻断 | 不收集任何个人数据，不装 Cookie，无遥测。**这是当前架构的天然优势**——只要不引入遥测，就一直安全。 |
| **开源许可证合规** | ✅ 无问题 | 🟢 不阻断 | Godot 引擎 MIT 授权，导出时引擎版权声明已包含在二进制内。项目自写代码，无第三方库依赖需申明。唯一例外见 `assets-license.md` 红标。 |

## 🔴 阻断项汇总（按严重度）

1. **版号 / 软著 / 主体资质** —— 走国内渠道的前提，一件都没有，且周期长。**这一项决定了国内渠道当前不可行。**
2. **Steamworks 账号 + 提交费 + 税务表** —— 走 Steam 的前提，一件都没有。**必须人本人做，机器人不能代注册、代付款、代填税表。**
3. **开场视频来源不明** —— 见 `assets-license.md` 红标。**在来源确认前不进任何发行包。** 这一项是我能自己推动解决的（移除或替换），但需要人先回答来源。
4. **字体在非 Windows 机器上会缺字** —— 见 `assets-license.md` 黄标。会卡住 Steam Deck / Linux 用户。**需 @木匠 改工程。**

## 🟡 建议现在就做的低成本项

- 写一句「本游戏不收集任何个人信息」的隐私声明，放进商店页。10 分钟的事，能应付大部分平台表单。
- `project.godot` 补 `config/version` 与版权字段（`application/config/copyright`）。**需 @木匠 或人授权我改。**
- 商店页脚注加一句「本作不含内购、不含广告、不联网」。
